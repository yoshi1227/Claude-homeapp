# Simple Home

Google Pixel 向けのシンプルなホームアプリ（ランチャー）です。

## 機能

- **右スワイプでアプリ一覧**：下スワイプのアプリ一覧はありません。ホーム画面を右にスワイプ（指を左から右へ）するとアプリ一覧が開きます（設定で左スワイプにも変更可）。ホーム画面で下にスワイプすると通知パネルが開きます。
- **カテゴリー別のアプリ一覧**：iPhone の App ライブラリのように、アプリをカテゴリーごとのフォルダにまとめて表示します。フォルダには 3 個のアイコンが直接表示され、残りは右下の小さなまとめ表示をタップすると全部表示されます。
- **名前なし・一文字アイコン**：アイコンにはアプリ名の最初の 1 文字だけを表示します。アプリ名は表示しません（長押しメニューで確認できます）。
- **アプリの非表示**：アイコンを長押し →「非表示にする」。設定の「非表示のアプリ」からいつでも元に戻せます。

### 長押しメニュー

アイコンを長押しすると次の操作ができます。

- ホームに追加 / ホームから外す（ホーム画面での並び替えも可）
- カテゴリーを変更（自動判定が合わない場合）
- 非表示にする
- アプリ情報 / アンインストール

### 設定の開き方

- ホーム画面の何もないところを長押し
- またはアプリ一覧右上の歯車アイコン

## インストール

1. GitHub の **Actions** タブ →「Build APK」の最新の実行を開き、`SimpleHome-debug-apk` をダウンロードして解凍します。
2. Pixel に APK を転送してインストールします（「提供元不明のアプリ」の許可が必要です）。
   `adb` を使う場合: `adb install -r app-debug.apk`
3. ホームボタンを押して「Simple Home」を選ぶか、
   **設定 → アプリ → デフォルトのアプリ → ホームアプリ** で「Simple Home」を選びます。

## 自分でビルドする

Android Studio でこのフォルダを開くか、Android SDK がある環境で次を実行します。

```sh
./gradlew assembleDebug
# 出力: app/build/outputs/apk/debug/app-debug.apk
```

## カテゴリーの決め方

アプリが自己申告しているカテゴリー（Android の `ApplicationInfo.category`）を使います。
申告が無いアプリはよく使われるアプリのパッケージ名から推測し、それでも分からない場合は
プリインストールアプリなら「ツール」、それ以外は「その他」になります。
長押しメニューからアプリごとに変更できます。
